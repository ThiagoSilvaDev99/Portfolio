Projetos

API E-commerce - Loja de Roupas

API RESTful desenvolvida em Java 21 e Spring Boot para o motor de um sistema de e-commerce. A arquitetura foi desenhada com foco em alta consistência de dados, adotando princípios de Domain-Driven Design (DDD) e uma organização de código orientada a domínios de negócio (Feature-Based).

O destaque técnico é a implementação de um Modelo de Domínio Rico, que blinda as entidades contra estados inválidos. O projeto utiliza PostgreSQL modelado para categorias hierárquicas, mapeamento híbrido avançado com MapStruct e Lombok, além de rotinas de higienização silenciosa de dados para garantir a integridade do banco.

Workshop Spring Boot com MongoDB

API RESTful desenvolvida em Java e Spring Boot com foco no paradigma orientado a documentos (NoSQL) utilizando MongoDB e Spring Data. A aplicação adota uma arquitetura em camadas bem definida, implementando o padrão DTO para segurança e otimização do tráfego, além de tratamento global de exceções.

O destaque técnico está nas decisões de modelagem de dados NoSQL, equilibrando o uso de referências relacionais (@DBRef) e objetos aninhados para maximizar a performance de leitura. O projeto também explora consultas avançadas utilizando a anotação @Query (com sintaxe JSON) e o uso de Docker para a conteinerização do banco de dados.

Projeto REST API - Curso DevSuperior

API RESTful desenvolvida em Java e Spring Boot focada na consolidação dos fundamentos de desenvolvimento backend. O projeto utiliza Spring Data JPA (Hibernate) para o Mapeamento Objeto-Relacional (ORM) de entidades como Usuários, Produtos e Categorias, além do banco de dados em memória H2 para validações rápidas.

A aplicação foi estruturada seguindo o padrão de Arquitetura em Camadas (Controllers, Services e Repositories). O destaque técnico recai sobre a implementação de boas práticas, como o Database Seeding para o povoamento inicial e um Tratamento Global de Exceções padronizado, garantindo o retorno de respostas HTTP semânticas e descritivas na API.
